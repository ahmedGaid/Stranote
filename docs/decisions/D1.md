# Decision D1 - `01_Tasks` vs `01_Tickets`

## Question

Packs list `01_Tasks` (accountant, general, nurse, software-developer) but the engine requires `01_Tickets` (`RequiredWorkFolders = @('01_Tickets', '99_Archive')` in `src/StranoteCore.ps1:23`; `StranotePacks.ps1:239` notes the engine keeps tasks in `01_Tickets` whatever the pack lists). `01_Tasks` is unused everywhere except the pack lists. Should packs keep `01_Tasks`, switch to `01_Tickets`, or should the engine honor whichever folder the pack lists?

## Options

**A. Keep `01_Tasks` in packs (status quo)**
- Cost: none — no file changes, no migration, no test impact.
- Risk: inconsistency remains between pack lists and engine default; `PHASE_REVIEW.md:76` already flags it ("engine default; packs list an unused `01_Tasks` | Board D1"). Onboarding on non-EBS packs can still throw if code ever trusts pack lists (`specs/001-career-packs-onboarding/tasks.md:153`).
- Unblocks: nothing; defers the decision.

**B. Switch packs to `01_Tickets` (recommended)**
- Cost: pack text only — `packs/accountant.json`, `general.json`, `nurse.json`, `software-developer.json` (one string each); docs mention `01_Tasks` nowhere except pack lists, so no docs change.
- Risk: very low — `01_Tasks` is unused, so renaming the pack entry changes no behavior; reversible by editing the packs back.
- Unblocks: D1 resolved; pack lists match the engine and onboarding tests (`tests/StranoteOnboarding.Tests.ps1:68` expects `01_Tickets`).

**C. Make the engine honor pack-listed folders (drop hard requirement)**
- Cost: engine change in `src/StranoteCore.ps1`, `src/StranotePacks.ps1`, tests; migration for existing roots.
- Risk: higher — changes task storage location semantics; needs spec + tests; belongs to Phase I per `PHASE_REVIEW.md:48`.
- Unblocks: pack authors choose any task folder; not needed now.

## Recommendation

**B**: switch the four packs to `01_Tickets`. It is pack-text only, matches what the engine already requires and tests expect, and is fully reversible. Do not decide for the owner: pick A, B, or C and reply with the choice; I will then close D1 and (for B) a follow-up row can retouch the packs.
